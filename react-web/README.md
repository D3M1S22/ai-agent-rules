- **Data Fetching**: Mandatory use of `@tanstack/react-query` with centralized query key factories.
- **UI/UX**: Tailwind CSS strict conventions and WCAG AA accessibility enforcement.
- **State**: Immutability principles and proper Hook orchestration.
